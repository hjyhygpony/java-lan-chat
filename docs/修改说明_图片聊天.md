# 图片聊天功能修改说明

## 修改后的行为

- 收到 PNG、JPG、GIF、BMP 等能够被 Java ImageIO 识别的图片后，不再自动保存到 `received_files`。
- 图片会以缩略图形式直接显示在聊天记录中。
- 鼠标移动到图片上时变为手形指针，点击即可打开大图预览。
- 大图窗口支持“缩小”“适应窗口”“原始大小”“放大”。
- 只有点击“保存图片…”并选择路径后，图片才会写入磁盘；若文件已存在，会询问是否覆盖。
- 收到非图片文件时，仍按原逻辑自动保存到 `received_files`。

## 主要修改文件

`src/com/cncd/ch04/client/ChatClient.java`

网络协议和服务器端文件传输逻辑没有改变，因此原来的群聊、私聊、好友、资料和普通文件传输功能保持不变。

## 测试方法

1. 执行 `compile.bat`。
2. 启动 `run_server.bat`。
3. 启动两个 `run_client.bat`，分别登录两个用户名。
4. 在发送端在线用户列表中选择接收者，点击“发送文件/图片”，选择一张图片。
5. 接收端聊天区出现缩略图；点击图片打开预览并测试缩放、保存。
